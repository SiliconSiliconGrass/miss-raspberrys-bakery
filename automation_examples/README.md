# 自动化脚本示例

> [!WARNING]
> 强烈建议玩家优先尝试自己独立编写自动化脚本，以获得最完整的游戏体验！
>

本文件夹中存放有自动化脚本示例，均为Python编写，使用uv进行环境管理。
仅供参考，不一定是最好解法。
鼓励玩家尝试使用自己喜爱的编程语言编写自动化脚本。

| 文件夹 | 对应游戏 | 说明 |
| --- | --- | --- |
| `solution_baking/` | 充能面包 `/game-baking` | 把每关解成模 2 线性方程组，算出要点哪些格子 |
| `solution_cargo/` | 货物装箱 `/game-cargo` | 先找出行列需求对应的图案，再做拼图的精确覆盖求解 |

示例运行方式：

首次运行前安装依赖环境
``` sh
uv sync
```

运行
``` sh
uv run main.py
```
